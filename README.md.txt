# Health Symptom Tracker


 **Technology Stack** used in this application
- **ASP.NET Core 10 Web API** (C#)
- **SQL Server** , MongoDB, Redis
- **Tailwind CSS**
- **Angular** 
- **Azure** + Docker for deployment
- **XUnit**
- **Scalar, Postman**
- **Azure Blob Storage**

---


<small>

| Feature | Details |
|---|---|
| User Authentication | User Registration, Login, LogOut, Change Password, Forgot Password/Username
| Diagnosis | Add/Edit/Delete Diagnosis
| Symptoms and Relief | Add/Edit/Delete Symptoms and its relief, Track Symptoms
| Medications | Add/Edit/Delete/Track Medications
| Daily Journal | Add/Edit/Delete/Search Journal

</small>
